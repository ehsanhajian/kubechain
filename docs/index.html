KubeChain

Is my Kubernetes blockchain deployment production ready?

KubeChain only reads. A live check uses get, list, and watch. Secret bytes are discarded. Volume snapshots are observed and never created. The cluster is left as it was found. KubeChain does not apply a manifest and does not create a snapshot.

Install

Python 3.11 or newer. kubechain --version prints the release.

pip install kubechain
kubechain --version
kubechain check --manifests examples/ready
kubechain check --namespace nodes

Verdict

  • ready, exit 0. No warning or critical finding.
  • review, exit 1. A warning names a production gap.
  • not-ready, exit 2. A critical finding. Chain data, a secret, or an upgrade would be unsafe.

The full reference is the README. The package is on PyPI.
